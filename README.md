# YFT Zimmet Defteri

Askeri birliklerde malzeme envanteri, zimmet ve arıza takibi.

## Çalıştırma

```bash
npm install
npm run dev
```

İlk giren kişi kol komutanı olarak birliği kurar. Personel kullanıcı adı sicil numarasıdır.

## Roller

- **Kol komutanı:** envanter, zimmet, personel, belge, yetki.
- **Yetkili:** komutanın verdiği tam veya sınırlı yetki.
- **Personel:** yalnız kendi zimmeti.
